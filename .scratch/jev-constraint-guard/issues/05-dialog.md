# 05: 对话框三选项

**What to build:** 模型认为某次改动违反了约束时，开发者不该只看到一句「被拦了」。他要看到是哪条规则、规则写在哪个文件里、以及模型给出的实际概率是多少——最后这一项是他日后把阈值调到合适数值的唯一依据。然后他有三条路：把改动打回让 agent 自己改正；这一次放行（一次性的合理例外，不必去改约束文件）；或者本会话内不再为这条规则问他（某条规则在当前任务上反复误报时，没有这个选项他就要对着同一条规则按十次放行，接着就会把插件卸了）。按 Esc 等于打回——关掉对话框应该是保守动作而不是放行。对话框不会自己倒计时消失。一次改动同时踩了几条规则时，一起列出来，他改一遍就能全修掉。

## 偏离：多条违规时的忽略语义

初版实现在多条违规时把整批都加进忽略列表，但选项标签是单数的「Ignore **this** constraint」——一次按键会关掉用户没点名的规则，违反 PRD story 44（「silence **one** constraint」）。

修正后：只有一条违规时标签仍为单数、直接静音那一条；多条时标签改为「Ignore one of these constraints…」并弹出二级选择。二级选择按 Esc 回退到打回，不静音任何规则。
