# 08: `/jev-guard` 命令

**What to build:** 这个功能最可能的失败方式是：开发者以为自己写了一条约束，守卫却把它切成了三条、或者把三条并成了一条，于是判断结果看起来毫无道理——而没有这个命令，这件事完全不可见。命令的首要价值就是让他能看到「你的 md 被识别成了这 7 条，分别来自哪个文件」，从而在信任守卫之前先确认它读懂了。顺带能看到生效的阈值和模型（key 脱敏），确认配置真的加载了；能看到本会话忽略了哪些规则，免得忘了自己关过什么；能清空忽略列表，在冲突的任务结束后把规则重新打开；也能本会话停用整个守卫，让一段专注的工作不被打断，而不必卸载插件。
