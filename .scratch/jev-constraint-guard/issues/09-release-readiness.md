# 09: 发布就绪

**What to build:** 别人能通过 pi 的包机制装上这个扩展，并且装完就能用。README 要让他在五分钟内知道：怎么配 key、约束文件放哪、他的 markdown 会被怎么切、被拦下时那三个选项分别意味着什么。还要讲清两件容易踩的事：阈值默认值是推理出来的、应当用日志功能把它换成自己项目的数值；以及日志会原样记录文件变更内容（虽然落在项目外，但他有权知道）。
