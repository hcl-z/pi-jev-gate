# 07: 日志

**What to build:** `0.6` 这个默认阈值是推理出来的，不是量出来的。开发者要把它换成一个来自真实决策的数值，就需要一份能统计的记录：每次检查送出了什么、模型返回的每条概率是多少、以及**他自己按了哪个按钮**——他的选择就是标定阈值所需的标注数据。所以是一行一条 JSON，方便 `jq` 出来批量看，而不是人肉翻两百条分段文本。降级放行也要记，否则事后他会困惑为什么某次没拦。日志默认关闭，开了以后落在 pi 的 agent 目录而非项目目录里——正因为它在项目外，变更内容可以原样记录、不必截断，不存在被提交进仓库的风险。API key 任何形式都不出现。磁盘满或权限不对时，告警一次然后彻底忽略，绝不因为写不了日志而改变放行或阻断的结果。

**Blocked by:** 05, 06
