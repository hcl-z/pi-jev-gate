# 03: 切分完整性

**What to build:** 开发者的约束文件是他为了给人读而写的，不是为了迁就工具。一条规则带着它的补充说明和例外（标题下面挂几个 bullet）应当被当作**一条**约束整体判断，而不是被切成几条互相打架的独立规则。有些人根本不写标题、只写一个扁平的 bullet 列表，那也要能用，每个顶层 bullet 算一条。`###` 和 `##` 同等对待。他能在守卫的报告里看到规则被识别成了什么名字。某条规则写得特别长（比如带代码示例）时，会被截断而不是撑爆请求。文件里全是散文、切不出任何条目时，守卫什么都不做。
