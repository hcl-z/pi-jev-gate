# Reference Docs

How the engineering skills should consume this repo's reference resources.

## The document

`docs/reference/index.md` indexes the repo's reference resources: external specs, API docs, vendor documentation, and whatever else explains why this code is the way it is. The resources themselves live beside it under `docs/reference/`.

## Before looking outside the repo

Read `docs/reference/index.md` first when you need external material about a dependency, a protocol, or a format this repo depends on. Search the web only when the index turns up nothing.

When you add a resource, it gets a file under `docs/reference/` and an entry in the index — the index is the only way anything there is meant to be found.

## When it doesn't exist

Proceed silently. Don't flag its absence, and don't create it — a dedicated skill writes this document, as material worth keeping accumulates.
